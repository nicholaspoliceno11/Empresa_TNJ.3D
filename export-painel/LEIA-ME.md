# Painel Campanha 2026 — arquivos para copiar no Google Apps Script

Identidade visual **Renan Filho / Senador Renan** aplicada em `Styles.html`, `Index.html` e `Login.html`.

## Como usar

1. Abra o [editor do Apps Script](https://script.google.com/home/projects/1epspmLLlbedpTZ8HzeGB0-XMI06kMe4ozDOTdwLmwfRsMaHvaMr7pd0Y/edit).
2. Para cada arquivo abaixo, clique em **Abrir código (Raw)** → `Ctrl+A` / `Cmd+A` → copiar → colar no arquivo correspondente no editor.
3. Salve tudo (`Ctrl+S`) e crie uma **nova implantação** da Web App.

> **Dica:** no Mac, use `clasp pull` antes de editar localmente e `clasp push` + `clasp deploy` para publicar.
