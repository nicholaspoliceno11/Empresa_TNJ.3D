Eleições 2026 — Painel de Gestão

Frontend estático + Google Apps Script (planilha como banco de dados)

Primeiros passos

  1. Clone este repositório e entre na pasta do projeto.
  2. npm install
  3. npm run clasp:login (Apps Script API ativada)
  4. npm run clasp:pull — baixa o código do Google
  5. npm run clasp:push e npm run clasp:deploy
  6. Cole a URL /exec em assets/js/config.js
  7. npm run dev — abre em http://localhost:8080
